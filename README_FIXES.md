# LawNexa Fixed & Updated Bundle Package v4.0

Is ZIP file me lawyer specializations ke liye dynamic custom entry input (Maximum 3 Categories) add kar diya gaya hai.

## Updated Features:
- **No Static Checkboxes**: Lawyer apni custom specialization category type kar ke "+ Add" button ya Enter se add kar sakta hai.
- **Limit**: Maximum 3 categories per advocate enforced on UI & Backend.
- **Tag Chips UI**: Selected specializations yellow chips/badges ki soorat me show hoti hain aur easily delete (X) ho sakti hain.
